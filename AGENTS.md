
# Project Instructions
Before creating, modifying, or refactoring any UI, **read `.agents/agents` first**.


## UI/UX Rules

- Inspect existing components before creating new ones.
- Keep the design minimal, consistent, and responsive.
- Mobile-first behavior is required.
- Do not add unnecessary dependencies.
- Use existing design tokens, fonts, colors, and icons.
- All interactive elements must have accessible labels.
- Respect prefers-reduced-motion.
- The mobile bottom dock must not cover important content.
- Run lint and build after UI changes.
